# Prompt-Generator-Pro

Prompt Generator Pro is a tool for creating detailed and customizable AI prompts.

## About

Prompt Generator Pro gives you detailed control over different visual and creative aspects of your prompts. You can customize colors, lighting, camera settings, mood, dimensions, quality and other visual parameters.
You can also save a complete style as a JSON file and import it later to restore the same settings.

## Features

* Create detailed AI prompts
* Customize visual styles
* Choose colors and color combinations
* Control lighting
* Choose camera angles and camera settings
* Define mood and atmosphere
* Control image dimensions and aspect ratio
* Configure image quality
* Customize other visual and creative parameters
* Export styles as JSON files
* Import styles from JSON files
* Save and reuse custom styles
* Copy generated prompts easily

## Style System

The style system gives you detailed control over the visual properties of your prompts.
You can customize color, lighting, camera angle, camera settings, mood, atmosphere, dimensions, aspect ratio, quality and other visual settings.
You can export your complete style as a JSON file and upload it later to restore the saved settings.

## Requirements

Node.js is required to run the project.
Download Node.js from:
https://nodejs.org/

## Installation

Clone the repository:

```bash
git clone https://github.com/mehran154sorosh/Prompt-Generator-Pro.git
cd Prompt-Generator-Pro
```

Open CMD or Terminal inside the project folder and install the dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Open the local URL shown in the terminal in your browser.
The URL will usually look like:

```text
http://localhost:5173
```

The port might be different depending on your setup.
